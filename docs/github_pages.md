# Publish the project portfolio

The project repository is https://github.com/bivolgh-max/fleet-system. Its README can be used as the digital portfolio link immediately after publication.

The separate static portfolio is already prepared in `docs/index.html`. Enable GitHub Pages in the repository settings:

1. Open https://github.com/bivolgh-max/fleet-system/settings/pages.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Select the **main** branch and the **/docs** folder.
4. Click **Save** and wait for the Pages deployment to finish.
5. Open the website URL displayed by GitHub. Check the heading, ERD, repository link and documentation links.
6. Add that verified URL to the assessment only after the page opens successfully.

The expected default URL is `https://bivolgh-max.github.io/fleet-system/`. This is an expected address, not evidence that the site has been enabled or deployed.

The GitHub connection used to upload the source cannot change Pages administration settings, so this setting still requires the account owner. No custom domain, paid service or GitHub Actions workflow is needed for this static page.

GitHub Pages hosts static portfolio files. Use the README's Windows XAMPP instructions to run the PHP application and database.

Source: GitHub Docs, [Configuring a publishing source for your GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site), accessed 13 October 2026.
